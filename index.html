treemd macht aus jedem Verzeichnis eine saubere, einfügungsfertige Markdown-Liste – für READMEs, Notizen und Dokumentation.

treemd.sh herunterladen ↓ Ausgabe ansehen

Ein Befehl. Fertig.

Ordnung, die du direkt einfügen kannst.

Keine Nachbearbeitung, kein Nachzeichnen. treemd gibt ausschließlich gültiges, unformatiertes Markdown aus – bereit für deine Doku.

terminal — docs 
$ ./treemd.sh docs
- docs/
  - LOG.md
  - STATE.md
  - sessions/
    - 2026-09-16-grundgeruest.md

# kopieren · einfügen · fertig

Klein im Code. Sorgfältig im Detail.

Gebaut für echte Verzeichnisse.

01 / PORTABEL

Läuft einfach

POSIX sh und nur Standardwerkzeuge. Keine Installation, kein Paketmanager, keine Runtime.

02 / ROBUST

Sauberes Markdown

Sonderzeichen werden maskiert und ungewöhnliche Dateinamen bleiben zuverlässig in einer Zeile.

03 / KONTROLLIERT

Du bestimmst die Tiefe

Blende Punktdateien ein, begrenze Ebenen oder folge Symlinks – mit eingebautem Zyklusschutz.

Direkt loslegen

Zwei Zeilen bis zum ersten Baum.

Datei laden, ausführbar machen und auf ein Verzeichnis zeigen.

chmod +x treemd.sh && ./treemd.sh docs

Optionen: -a Punktdateien · -L Symlinks · -d TIEFE Ebenen
